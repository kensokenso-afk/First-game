# assets/

Tempat aset pixel (sprite, tileset, latar). Area Gemini CLI.

Aturan singkat:
- Format PNG, tanpa antialias, ukuran kelipatan 2 jika memungkinkan.
- Nama file huruf kecil dengan tanda hubung, mis. `player-run.png`.
- Catat aset baru di `HANDOFF.md`.
