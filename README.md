# First-game

Game pixel berbasis **Phaser 3** (JavaScript), dikerjakan bersama Claude dan Gemini CLI.

## Menjalankan
```bash
python3 -m http.server 8000
```
Lalu buka `http://localhost:8000` (di Codespaces: buka tab Ports, port 8000).

## Kontrol
- Keyboard: panah kiri/kanan, panah atas atau spasi untuk lompat.
- Sentuh (HP): layar dibagi 3, kiri = jalan kiri, tengah = lompat, kanan = jalan kanan.
